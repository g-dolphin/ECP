# Public Scope

This repository is the public distribution for ECP methods, documentation, and selected published outputs.

## Included in public

- Methodology and data-processing code required for core ECP compilation and reporting.
- Documentation of data sources, pipeline steps, and output structure.
- Published output datasets and report artifacts intended for open release.

## Excluded from public

- Restricted-source or licensed workflows and their intermediate assets.
- Large generated check artifacts not required for public reproducibility.
- Local development/cache files (`__pycache__`, `.ipynb_checkpoints`, `.Rhistory`, `.DS_Store`, editor settings).

## Notes on transparency

The public repository keeps source descriptions and pipeline documentation so users can understand derivation logic, while excluding content that cannot be safely or legally redistributed.
